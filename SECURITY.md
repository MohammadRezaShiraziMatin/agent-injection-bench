# Security Policy

## Scope

**agent-injection-bench** is a research benchmark and harness for studying **indirect prompt injection (IPI)** leading to **tool misuse** in tool-using LLM agents. Episodes use **mock offline tools** (for example, simulated search and email). The repository is intended for controlled, reproducible evaluation—not for operating live attack infrastructure against third-party systems.

## Reporting a vulnerability

If you believe you have found a **security vulnerability in this repository** (code, CI, dependencies, or release artifacts), please report it **privately**:

1. **Preferred:** [GitHub Security Advisories](https://github.com/MohammadRezaShiraziMatin/agent-injection-bench/security/advisories/new) for this repository (Private vulnerability reporting).

Please do **not** open a public GitHub issue for undisclosed security problems.

## What we are not asking for

- Do **not** report live attacks, penetration tests, or abuse against **third-party services**, APIs, or people using this bench as justification.
- Do **not** paste **secrets**, API keys, tokens, or personal data in issues or advisories.

## Response

We will acknowledge private reports when possible and work toward a fix or documented mitigation. Timing depends on maintainer availability; this is a research project without a formal SLA.
